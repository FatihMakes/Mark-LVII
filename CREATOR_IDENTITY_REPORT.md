## 2. 7-Stage Cognitive Reasoning Loop

Implemented in `core/creator_brain.py`, every complex query or task traverses a structured cognitive lifecycle:

```
[OBSERVE] ➔ [UNDERSTAND] ➔ [REASON] ➔ [PLAN] ➔ [EXECUTE] ➔ [VERIFY] ➔ [REFLECT]
```

1. **OBSERVE:** Ingests raw input tokens, audio spectrograms, and system telemetry (CPU, RAM, active windows).
2. **UNDERSTAND:** Resolves user intent, detects language (English, Hindi, Hinglish), identifies target entities, and extracts affective state.
3. **REASON:** Evaluates security constraints, operational risk tier, cached history, and available tool capabilities.
4. **PLAN:** Formulates ordered sub-tasks with verifiable completion conditions and rollback fallbacks.
5. **EXECUTE:** Dispatches actions to background worker threads without blocking the Qt main GUI loop or voice stream.
6. **VERIFY:** Performs cryptographic, syntax, or binary verification of outputs (e.g. PyMuPDF checks for PDFs, HTTP status checks for APIs).
7. **REFLECT:** Updates local memory, records performance latency in telemetry logs, and adapts user preference weights.
